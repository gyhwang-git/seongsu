# Seongsu

**성수동 건축물 지도** — 서울 성동구 성수1가1동·성수1가2동·성수2가1동·성수2가3동의 건물을 사용승인연도·건축물 용도·30년 이상 노후 건물의 용도별로 색칠한 지도입니다. 건물 정보는 브이월드에서 받고, 배경지도는 인증키가 필요 없는 공개 타일을 씁니다.

- 지도: https://gyhwang-git.github.io/seongsu/ (탭 바로가기: `#use` 용도, `#old` 30년 이상 노후)
- 건물 6,239동 (성수1가1동 1,210 · 성수1가2동 1,343 · 성수2가1동 1,900 · 성수2가3동 1,786)
- **사용승인연도 탭**: 1969년 이전 / 1970년대 / 1980년대 / 1990년대 / 2000년 이후 / 승인일 정보 없음, 10년 단위 막대그래프
- **건축물 용도 탭**: 건축물대장 주용도 대분류를 9개로 묶음, 용도별 건수·비율 막대

  | 분류 | 포함 주용도 | 건물 수 |
  |---|---|---:|
  | 단독주택 | 단독주택 | 1,867 |
  | 근린생활시설 | 제1종·제2종 근린생활시설 | 1,402 |
  | 공장 | 공장 | 450 |
  | 공동주택 | 공동주택 | 393 |
  | 업무·숙박·판매 | 업무·숙박·판매·위락시설 | 89 |
  | 창고·자동차·위험물 | 창고·자동차 관련·위험물 저장·운수시설 | 210 |
  | 교육·의료·복지·종교·문화 | 교육연구·의료·노유자·종교·문화집회·수련·운동시설 | 75 |

  | 용도 정보 없음 | (외곽선만 표시) | 1,743 |

- **30년 이상 노후 탭**: 올해 기준 사용승인 후 30년 이상(2026년 기준 1996년 이전 승인) 건물만 용도별로 색칠, 30년 미만은 회색, 승인연도 없음은 점선. 용도별 노후 건물 수와 노후 비율(승인연도 있는 건물 중) 막대
  - 2026년 기준 30년 이상 3,903동 = 승인연도 있는 4,710동 중 82.9% (단독주택 92.8%, 근린생활시설 88.9%, 공장 77.4%, 공동주택 40.5%)
- 공통: 행정동 필터, 범례로 구간 켜기·끄기(모두 끄기 후 하나만 보기), 행정동별 표, 배경지도 전환(회색·일반·어두운·위성)

> 성수2가에는 '성수2가2동'이라는 행정동이 없습니다(성수2가1동·성수2가3동). 네 행정동을 합친 범위는 법정동 성수동1가·성수동2가와 같습니다.

## 자료
- 건물: 국토교통부·브이월드 GIS건물통합정보 `LT_C_BLDGINFO` (사용승인일 `useapr_day`, 주용도, 층수, 연면적)
- 행정동 경계: [vuski/admdongkor](https://github.com/vuski/admdongkor) ver20261001
- 배경지도: OpenStreetMap(회색·어두운 지도는 CSS 필터 적용), Esri World Imagery — 모두 인증키 불필요

### 자료의 한계
- 원자료의 사용승인일은 1923–2018년 범위로, 2019년 이후 준공 건물은 반영되지 않았을 수 있습니다.
- 1,529동(24.5%)은 사용승인일이 비어 있어 '승인일 정보 없음'으로 표시합니다.
- 1,743동(27.9%)은 주용도가 비어 있습니다. 용도는 건축물대장 기준이라 현재 실제 쓰임(예: 공장을 고친 카페)과 다를 수 있습니다.
- 원자료에 2019년 이후 승인 건물이 없어 노후 비율이 실제보다 높게 나올 수 있습니다.
- 건물의 소속 행정동은 건물 폴리곤의 중심점 기준입니다.

## 브이월드 인증키
인증키는 건물 수집 스크립트(`scripts/download_buildings.mjs`)에서만 쓰며, 상위 폴더(또는 이 폴더)의 `.env`에 `V-WORLD_KEY=...`로 둡니다. 웹 페이지에는 키가 들어가지 않습니다.

## 다시 만들기
```
node scripts/download_buildings.mjs   # 브이월드에서 건물·경계 수집 → data/*.geojson
node scripts/build_data.mjs           # 지도용 data/seongsu_data.js 생성
python -m http.server 8000            # http://localhost:8000 에서 확인
```
